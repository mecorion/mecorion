
Для полного визуального комплекта v1 нужен примерно такой набор экранов.

### 1. Вход и первый запуск

1. Вход — уже есть.
2. Регистрация.
3. Восстановление пароля.
4. Подтверждение email.
5. Первый запуск Music:

   * выбор любимых жанров;
   * выбор исполнителей;
   * импорт музыки/плейлистов;
   * возможность пропустить настройку.
6. Empty State нового пользователя — главная без истории прослушиваний.

---

### 2. Главная

Аналог Spotify Home / «Главное» Яндекс Музыки.

7. Главная — уже есть.
8. Главная для нового пользователя.
9. Главная после накопления истории.

На ней нужны блоки вроде:

* «Продолжить слушать»
* «Недавно слушали»
* «Для вас»
* «Моя волна» / персональный поток
* новые релизы;
* любимые исполнители;
* подборки по жанрам;
* подборки по настроению;
* рекомендации на основе истории;
* тренды;
* популярное сейчас.

То есть визуально это один экран, но надо нарисовать 2–3 его состояния.

### 4. Исполнитель

Один из важнейших экранов.

20. Страница исполнителя.

На ней:

* большая обложка/фон;
* имя;
* verified;
* число слушателей;
* Subscribe / Подписаться;
* Play;
* Shuffle;
* популярные треки;
* дискография;
* альбомы;
* синглы;
* сборники;
* «С участием исполнителя»;
* похожие исполнители;
* описание;
* участники группы.

Для Mecorion это особенно важно из-за нашей модели Contributor.

Например, у `Кино` здесь можно показывать:

**Кино**
Группа

Участники:

* Виктор Цой — вокал, гитара
* Юрий Каспарян — гитара
* ...

Это сразу позволит проверить, удобно ли отображается наша модель ContributorKind / ContributorRole.

## Что я бы реально нарисовал для Mecorion Music v1

Чтобы не делать сотню почти одинаковых макетов, я бы свёл всё примерно к **30 ключевым визуалам**:

1. Login
2. Registration
3. Welcome / onboarding
4. Home
5. Home — new user
6. Search
7. Search results
8. Genre catalogue
9. Genre page
10. Artist
11. Album
12. Track
13. Playlist
14. My Music
15. Liked tracks
16. Albums library
17. Artists library
18. Playlist library
19. Listening history
20. Local Music
21. Local file explorer
22. Mini Player
23. Full Player
24. Lyrics
25. Credits
26. Queue
27. Personal Flow
28. Notifications
29. Music Settings
30. UI States / modals / context menus

Этого уже достаточно, чтобы v1 выглядела как полноценная музыкальная платформа уровня структуры Spotify/Яндекс Музыки, а не как несколько разрозненных страниц.

Причём твои текущие макеты уже закрывают примерно `1, 4, 20, 22, 23, 26`. Следующим логичным пакетом я бы проектировал **Search → Artist → Album → Track → Playlist → My Music**, потому что именно эти экраны формируют основной пользовательский маршрут музыкального сервиса.
