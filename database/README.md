# Mecorion DB 1.0

Устанавливаемая PostgreSQL-архитектура Mecorion: общие ресурсы, аккаунты,
единая авторизация, роли, каталог контента, медиа, Music и Video.

## Требования

- PostgreSQL 16+
- расширения `pgcrypto`, `citext` и `pg_trgm`
- запуск от роли, которой разрешено создавать схемы и расширения

## Установка

```bash
psql -v ON_ERROR_STOP=1 -d mecorion -f install.sql
```

Проверка:

```bash
psql -v ON_ERROR_STOP=1 -d mecorion -f tests/test_all.sql
```

Откат установленной схемы:

```bash
psql -v ON_ERROR_STOP=1 -d mecorion -f rollback.sql
```

## Порядок миграций

1. `000_bootstrap.sql` — расширения и схемы.
2. `010_core.sql` — сервисы, глобальные ресурсы и outbox.
3. `020_account.sql` — аккаунты, профили, подтверждённая личность и удаление.
4. `030_auth.sql` — способы входа, credentials, устройства и сессии.
5. `040_access.sql` — разрешения, роли, scopes и назначения.
6. `050_content.sql` — контент, публикации, контрибьюторы и дубли.
7. `060_media.sql` — хранилище, assets, варианты и загрузки.
8. `070_workflow.sql` — заявки и согласования.
9. `080_moderation.sql` — жалобы, ограничения и апелляции.
10. `090_legal.sql` — правовые статусы, лицензии и takedown.
11. `100_library.sql` — коллекции, избранное, прогресс и offline grants.
12. `110_music.sql` и `120_video.sql` — расширения Music и Video.
13. `130_audit.sql` — неизменяемый аудит.
14. `seeds/*` — начальные справочники, роли и типы.

## Важные правила

- SQL использует quoted camelCase-идентификаторы, чтобы сохранить регламент
  `t*`, `fnc*`, `pk*`, `uq*`, `ck*` и поля `createDtm`/`updateDtm`.
- Пароли, seed-фразы, refresh-токены и OTP никогда не сохраняются открытым
  текстом.
- `publicId` предназначен для API. Внутренний `id` не публикуется наружу.
- Тяжёлые файлы не хранятся в PostgreSQL.
- Удаление аккаунта не означает автоматическое удаление юридически значимого
  аудита и обезличенного пользовательского контента.
- Пять лет хранения доказательства уникальности человека — начальная политика,
  а не навечно зашитый в структуру срок.

Подробные границы и инварианты описаны в
`docs/architecture-contract.md`.
