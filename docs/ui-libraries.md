# UI-библиотеки Mecorion

## Результат рефакторинга

Frontend использует две самостоятельные SCSS-библиотеки:

- `apps/web/src/styles-v1` — основной строгий интерфейс для первого запуска;
- `apps/web/src/styles-v2` — более мягкий интерфейс со скруглениями, тенями и
  прозрачными поверхностями.

Обе версии содержат одинаковые селекторы, публичные CSS-переменные и структуру
каталогов. Компоненты Vue не знают, какая версия подключена. Версии не
импортируют друг друга.

## Выбор версии

Версия выбирается пользователем на странице `/settings`. Переключение
применяется сразу, без перезапуска dev-сервера или повторной сборки. Выбор
сохраняется в `localStorage` под ключом `mecorion-ui-version`; при первом
запуске используется `v1`.

Обе библиотеки компилируются Vite как CSS-строки. Модуль
`apps/web/src/styles/uiVersion.js` помещает активную библиотеку в управляемый
элемент `<style>` после CSS сторонних компонентов, поэтому тема Mecorion имеет
предсказуемый приоритет. Атрибут `data-ui-version` элемента `<html>` отражает
текущий выбор.

## Архитектура

```text
styles-vN/
├── main.scss
├── mcrn-root.scss
├── mcrn-light-theme.scss
├── mcrn-dark-theme.scss
├── mcrn-media.scss
├── foundation/
│   ├── mcrn-core.scss
│   └── mcrn-foundation.scss
├── components/
│   ├── mcrn-button.scss
│   ├── mcrn-card.scss
│   ├── mcrn-input.scss
│   ├── mcrn-layout.scss
│   ├── mcrn-service.scss
│   └── mcrn-element-plus.scss
├── layouts/
│   ├── mcrn-shell.scss
│   ├── mcrn-workspace.scss
│   └── mcrn-legacy.scss
├── pages/
│   ├── mcrn-auth.scss
│   ├── mcrn-profile.scss
│   ├── mcrn-publications.scss
│   ├── mcrn-spaces.scss
│   └── mcrn-uikit.scss
└── style/
    ├── music/mcrn-init.scss
    ├── video/mcrn-init.scss
    ├── book/mcrn-init.scss
    └── course/mcrn-init.scss
```

`mcrn-root.scss` хранит размеры, интервалы, типографику, радиусы, точки
перестроения и совместимые переменные старых компонентов. Файлы тем содержат
полные цветовые палитры для `light` и `dark`. Все media queries находятся в
`mcrn-media.scss`. Сервисные акценты и правила расположены в соответствующих
`style/<service>/mcrn-init.scss`.

`layouts/mcrn-legacy.scss` временно сохраняет правила старых Video pages и
`MainLayout`. Его можно удалить после удаления соответствующих routes и Vue-
компонентов. Он является частью каждой библиотеки и не зависит от старого
каталога `styles`.

## Темы

Существующий Pinia store добавляет класс `light` или `dark` элементу `<html>`.
Тема и версия UI выбираются независимо:

```text
v1 + light
v1 + dark
v2 + light
v2 + dark
```

При добавлении цветовой переменной её необходимо определить в обоих theme-
файлах каждой библиотеки. Размеры и прочие общие параметры следует добавлять в
`mcrn-root.scss` с одинаковым публичным именем в v1 и v2.

## Добавление компонентов и сервисов

Переиспользуемый компонент добавляется в `components/mcrn-<name>.scss` обеих
версий и подключается из `main.scss`. Селекторы и публичные переменные должны
совпадать, визуальные значения могут различаться.

Сервисное оформление добавляется в `style/<service>/mcrn-init.scss`. Если
сервису нужен собственный акцент, его следует задавать на корневом классе
сервиса через публичные переменные. Разметка страницы не должна меняться при
переключении версии.

Адаптивные изменения добавляются только в `mcrn-media.scss`. На ширине 180px
разрешается перестраивать сетки, переносить управляющие элементы и уменьшать
отступы. Функциональные кнопки и навигация должны оставаться доступными.

## Проверки

Статическая проверка сравнивает структуру, селекторы, публичные переменные,
полноту тем и отсутствие перекрёстных импортов:

```bash
npm run ui:check
```

В ходе рефакторинга страницы были просмотрены в v1/v2 и light/dark на ширинах
180, 240, 320, 375, 768, 1024, 1440 и 1920px. Проверены landing, auth,
dashboard, роли профиля, Spaces, публикации, UI kit, Music, Video, Book, Course
и старые Video pages. Автоматизированные браузерные тесты в проект не добавлены.

## Выполненные исправления

- устранено смешение старых переменных, новых theme-файлов и Element Plus;
- все визуальные константы компонентов вынесены в корневые либо тематические
  CSS-переменные;
- media queries собраны в одном файле каждой библиотеки;
- сервисы Music, Video, Book и Course получили отдельные входные файлы;
- общие кнопки, поля, карточки и Element Plus разделены по компонентным файлам;
- минимальная ширина документа снижена с 320px до 180px;
- узкие сетки dashboard, profile, Spaces, UI kit и сервисов перестраиваются в
  одну колонку;
- off-canvas sidebar ограничен шириной viewport;
- мобильные Music controls, очередь и переход ко всем сервисам доступны;
- формы, длинный текст, карточки, фильтры, читалка, видеопросмотр и учебная
  практика не создают неконтролируемый горизонтальный overflow;
- добавлена поддержка `prefers-reduced-motion`.
