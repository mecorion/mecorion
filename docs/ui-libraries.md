# Mecorion UI

Frontend использует одну SCSS-библиотеку: `apps/web/src/styles/v2`.

Главная точка входа `apps/web/src/styles/main.scss` подключает её в глобальные
стили Nuxt. Динамического выбора версии и сохранения варианта в `localStorage`
нет.

## Архитектура

```text
styles/v2/
├── main.scss
├── mcrn-root.scss
├── mcrn-light-theme.scss
├── mcrn-dark-theme.scss
├── mcrn-media.scss
├── foundation/
├── components/
├── layouts/
├── pages/
└── style/
```

`mcrn-root.scss` содержит размеры, интервалы, типографику, радиусы и публичные
переменные. Файлы тем определяют палитры `light` и `dark`. Общие компоненты
находятся в `components`, страницы — в `pages`, сервисные стили — в
`style/<service>`.

## Правила расширения

- Использовать токены `--mc-*` вместо локальных визуальных констант.
- Переиспользуемые компоненты размещать в `components/ui` и экспортировать из
  `components/ui/index.js`.
- Проверять светлую и тёмную темы, ширины от 180 px до широких экранов.
- Не допускать переполнения flex/grid-контейнеров; использовать `min-width: 0`.

## Проверка

```bash
npm run ui:check
```

Команда проверяет структуру библиотеки, компиляцию Sass, полноту светлой и
тёмной палитр и разрешение публичных CSS-переменных.
